ADISU OCHE ZEMEDKUN - PORTFOLIO WEBSITE

FILES
- index.html: complete responsive portfolio website
- Adisu_Oche_CV.pdf: full CV embedded in the website and available to download
- assets/profile.jpg: profile image
- assets/bank-project.jpg: Bank Management System image
- assets/library-project.jpg: Library Management System image
- assets/cert1.jpg and assets/cert2.jpg: certificate images
- assets/portfolio-qr.png: QR code asset

PUBLISH ON GITHUB PAGES
1. Extract this ZIP.
2. Open your repository: https://github.com/adisuoche01-creater/adisu-dev
3. Upload index.html, Adisu_Oche_CV.pdf and the entire assets folder to the repository root.
4. Commit the changes.
5. Open Settings > Pages and confirm the publishing source is the main branch and root folder.
6. Visit https://adisuoche01-creater.github.io/adisu-dev/

NOTES
- The contact form opens the visitor's default email application. It does not save messages on a server.
- Google Maps and Google Fonts require an internet connection.
- Replace assets/profile.jpg or certificate images with updated images if desired, keeping the same filenames.
- The CV is also available as a separate PDF in this folder.

Update: Animated IT-themed background image added. CV is hidden by default and opens in a modal when View / Download CV is clicked.
